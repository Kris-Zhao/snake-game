# Planning workflow

1. Read `AGENTS.md`, `docs/PRD.md`, the feature request, and relevant files.
2. Define scope and acceptance criteria; distinguish requirements from assumptions.
3. Identify affected files, dependencies, and architectural boundaries.
4. Outline implementation steps, edge cases, risks, and verification methods.
5. Return the plan and unresolved decisions to the coordinating agent for approval.

Do not modify repository files. Follow project-specific rules from `AGENTS.md`
and `docs/PRD.md` rather than inventing product behavior or treating a generated
plan as approved.
